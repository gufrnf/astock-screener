五、主线传导：为什么是半导体设备材料

外围费城半导体指数隔夜重挫逾 5%，A股资金却没跟随抛售芯片，而是加仓国产设备与封测—— 外围利空反过来强化了国产替代逻辑。传导链条如下：

上游驱动AI 算力放量 + 长鑫/长存扩产
→
中间变量晶圆厂新增产线设备采购
→
产业验证国产化率 35%→40%，招标口径 55%
→
受益环节设备/材料/零部件（刻蚀65%、薄膜61%、清洗63%）

可验证的订单数据：盛美上海在手订单 170.73 亿（同比 +88.2%）、 中微公司 2026 新签订单体量与增速创历史新高。SEMI 预测 2026 全球半导体设备销售额 1659 亿美元、同比 +23.2%。

传导时滞与瓶颈：量检测国产化率不足 10%、光刻仅 1%–2%，是继续爬坡的主要瓶颈； 零部件供应紧张压制短期交付。板块 PB 已在 96% 分位，任何资本开支或涨价斜率放缓都可能快速杀估值—— 这是交易性主题，不宜当作无脑中期持有。

七、自动选股程序（随附，可直接运行）

仓库内 screen.py 是一个零第三方依赖的命令行选股器：只用 Python 标准库， 调用东方财富公开行情接口，对全 A 股做风控过滤 + 多因子 z-score 打分。有 Python 3 即可运行。

python screen.py                       # 综合打分 Top20
python screen.py -s value   -n 15        # 低估值蓝筹
python screen.py -s growth  -n 20        # 高景气动量
python screen.py -s dividend             # 红利防御
python screen.py -s value --json         # JSON 输出（可接其他系统）

打分因子：估值（PE/PB 倒数）、动量（涨跌幅）、量能（量比）、资金（主力净占比）、 流动性（成交额对数）；不同策略用不同权重。程序已内置剔除亏损/ST/市值与价格越界的风控。

本地试运行（2026-11-17 11:41 行情，1201 只有效候选）中，低估值策略筛出的前列为 民生银行、青农商行、贵阳银行、华夏银行、中国建筑等——与上文研报独立得出的「银行/建筑低估值」判断相互印证， 说明程序逻辑可用。
