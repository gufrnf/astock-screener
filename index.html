2「何时入 / 何时出」信号体系

本报告程序把 6 类技术指标转为可加减的分数：正分累积到阈值 = 关注买点，负分 = 关注卖点，中间 = 观望。

为什么不能只看单一指标？ 均线/MACD 有滞后性，RSI/KDJ 在趋势中会长期钝化，布林带在震荡市假信号多。 多指标共振（如「金叉 + 放量突破 + 站上 MA20」同时出现）能显著降低单一假信号概率——这也是成熟量化工具（如 KHunter）把 「选股 + 择时 + 风控 + 回测」做成一体的原因。

5自动程序 · 使用说明

trade_signals.py 仅用 Python 标准库，无需安装任何依赖，拉取东方财富公开接口即可运行。

# 全市场选股 + 择时（综合策略，看前10只）
python trade_signals.py

# 指定策略与数量
python trade_signals.py -s value -n 20

# 直接看某几只的买卖点
python trade_signals.py -c 002409 601211 000651

# JSON 输出（便于接入推送/自动提醒）
python trade_signals.py --json > signals.json

# 只看信号分布统计
python trade_signals.py --summary

配合定时任务（Windows 任务计划 / Linux cron）每日盘后运行，即可实现「每天自动选股 + 买卖点提醒」。接入钉钉/企业微信机器人 webhook 可把信号推送到手机——仓库 README 中有示例。
